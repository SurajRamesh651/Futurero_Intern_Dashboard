# 📊 Futurero Intern Dashboard (Power BI)

This repository contains the Power BI dashboard project created for **Futurero's Intern (YODAS) Program**, developed during my internship from **March 2023 to August 2023**. The dashboard provides interactive visuals and metrics for tracking intern attendance and departmental allocation.

---

## 🚀 Project Objective

To create a centralized Power BI dashboard hosted on SharePoint that allows real-time tracking of:
- Intern Attendance
- Department Assignment
- Performance Monitoring

---

## 🧠 Features

- ✅ Dynamic filtering by Intern ID, Department, and City
- 📈 Attendance metrics (Days Attended, % Attendance)
- 📊 Department-wise distribution
- 🧭 Drill-downs by individual intern
- 🎯 KPI indicators with conditional formatting

---

## 🗂️ Data Details

| Column Name       | Description                              |
|-------------------|------------------------------------------|
| Intern ID         | Unique ID (Starts from 7033710XX)        |
| Intern Name       | Indian names for personalization          |
| Email             | Intern's official email                   |
| Department        | App Dev, Cloud DE, EPM, Data Governance   |
| City              | Intern's work location                    |
| Days Attended     | Number of days attended out of 60         |
| Attendance %      | Calculated via DAX                        |
